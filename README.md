# DealScope frontend

Front end for [DealScope](https://github.com/RAM-cybe/dealscope), the Indian M&A target screener and peer valuation engine.

## Stack

- TypeScript
- Next.js
- pnpm

## Live site

- [https://dealscope-frontend.vercel.app](https://dealscope-frontend.vercel.app)

## Backend

Data and screening logic live in:

- [RAM-cybe/dealscope](https://github.com/RAM-cybe/dealscope)

## Run locally (high level)

1. Clone this repo and install with pnpm.
2. Copy any needed env vars from a local example (do not commit secrets).
3. Start the Next.js dev server.

See `SETUP.md` for setup notes.
